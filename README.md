# Hotel Tours AI Website

Official website for Hotel Tours AI, a UK provider that combines immersive Matterport 3D virtual tours with an AI concierge chatbot to help hotels turn website browsers into direct bookings. Part of the same family as [Gym Tours AI](https://gymtours.ai). Built with Next.js, Tailwind CSS, and TypeScript.

## Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the website.
